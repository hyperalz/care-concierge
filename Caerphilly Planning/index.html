Local API quick start

  1. Run the Digital Marketplace Search API locally (defaults to port 5009).
  2. Use the dev token myToken if you have not changed it.
  3. Click “Load from API” to replace demo data.

This demo reads the API directly in your browser. Keep it simple for GitHub Pages.
