# Cloud Procurement Workshop

Workshop for assessing cloud offerings against Digital Vision 2027 and procurement criteria.

## Fetch from Digital Marketplace

Paste a G-Cloud service URL (e.g. `https://www.applytosupply.digitalmarketplace.service.gov.uk/g-cloud/services/215840575690355`) and click **Fetch & populate** to pre-fill the form and apply rule-based score hints.

**Requirement:** Run the server so the fetch API is available.

```bash
cd "Cloud Procurement Workshop"
npm install
npm start
```

Then open **http://localhost:3001** in your browser.
